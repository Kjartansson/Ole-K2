Ole K2 — pair this browser

Ole K2 lets a local AI assistant drive this browser over a loopback-only connection. To keep anyone else from doing that, the extension and the local server share a token. Paste it once, here — it stays in this browser's local storage and is never sent anywhere except the local server on 127.0.0.1.

  1. The companion server must run on this machine. Easiest: ask your AI assistant — "Set up Ole K2 from github.com/Kjartansson/Ole-K2" — and it will do everything and hand you the token. Manually: ./install.sh in the Ole-K2 folder prints it, or read it with cat token.
  2. Paste the token below and press Save & connect.
